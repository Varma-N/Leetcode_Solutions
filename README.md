## ⚙️ What’s Inside

### 📂 `problems/`
This folder contains all my daily solved problems.  
Each problem has its own subfolder, named as:

```
problems/
├── 3354_make_array_elements_equal_to_zero/
│ ├── approach.md ← My explanation and thought process
│ └── solution.py ← The final, clean Python solution
├── 3355_next_problem/
│ ├── approach.md
│ └── solution.py
└── ...
```


🧱 **Naming format:**  
`<problem_number>_<problem_slug>`  
(e.g. `3354_make_array_elements_equal_to_zero`)
